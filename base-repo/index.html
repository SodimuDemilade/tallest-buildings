Tallest Buildings Rank

This interactive visualization compares the top 30 tallest buildings in the world as scaled silhouettes, giving you a true sense of relative scale.

How to Use

  • Skyline Canvas — Each silhouette is drawn to true relative scale. Hover for quick info.
  • Click a silhouette to see full building details including height, location, and year opened.
  • Filter by region, era, or search by name.
  • Height Stack — Toggle overlay showing how many buildings fit stacked on the tallest.

About

Data sourced from The Skyscraper Center (CTBUH). Heights represent architectural top (including spires). All measurements in meters.
